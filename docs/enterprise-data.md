# 企业数据连接第一版

本版实现**金蝶云星空只读接口适配、同步存储、页面和Agent查询**。默认使用显式标记的合成数据，不调用真实金蝶租户。用友和SAP保留厂商选项与连接器契约，尚未实现，启用时明确拒绝。

## 页面和安装

已有部署按原仓库方式重新构建镜像并迁移站点：

```powershell
docker compose up -d --build
docker compose exec -T backend bench --site focus.local migrate
```

迁移只增加本功能缺少的元数据，不重写已有连接、角色或配置。全新安装由 `suke_ops.setup.install` 安装。默认不创建连接，不创建企业或原生业务单据，也不启用自动同步。

登录后在业务搜索目录选择“企业数据连接”，或访问 `/desk/主页/erp-connections`。管理员可创建模拟连接，选择已有公司后发起全量重扫。每个对象提供三条合成记录，其中一条取消；应付有效记录未结金额为0.10+0.20=0.30 CNY。

配置使用 `ERP Connection` 原生表单：来源公司、账套、组织、UTC偏移、用户授权、同步对象、自动同步和过期阈值。一个连接对应一个来源组织与本地公司；多组织建立多个连接。已完成同步后来源身份及字段映射不可直接修改，需另建连接验证，原记录保留。

创建后“增量同步”或“全量重扫”只会排队；在“同步记录”检查最终 success/partial/failed/skipped 状态，再刷新查询。需要已有 long 队列worker。自动同步仅处理同时打开“启用连接”和“每15分钟自动同步”的连接。

## 权限

- System Manager／Administrator可配置连接、同步和查看任务；普通用户不能启动或改写同步。
- 每个连接的“可查询用户”默认空，普通用户须显式加入，且仍需本地公司读取权限。原生快照列表／导出关闭，受控页面执行搜索、计数、分页和精确汇总；原生详情也检查来源连接授权。
- 快照和任务由服务端上下文保护，不能通过REST改写，伪造客户端flags不能取得写权限。
- “允许模型使用”默认关闭。Agent调用还需连接和当前用户同时授权，管理员也须在“可查询用户”中单独打开模型许可；页面管理权限不等于数据外发许可。真实财务数据接入前应核对部署的模型服务和允许发送的字段。
- 密钥仅存Frappe Password加密字段，不进入页面查询响应、工具结果、同步日志或仓库。普通用户不能读取连接配置文档。

## 接口

所有接口均要求登录的企业内部账号；写接口只接受POST并保留Frappe原生CSRF／认证校验。

| 方法（前缀 `suke_ops.finance_sync.api.`） | 参数 | 返回 |
| --- | --- | --- |
| `connections` | 无 | 当前用户可见连接、实体、窗口和最后同步错误，不含凭据 |
| `records` | `connection`, `entity=payable`, `q`, `offset=0`, `page_length=20` | 分页记录、总数、分币种金额、合成／过期标记及来源时间 |
| `detail` | `name` | 一条经来源授权的只读标准快照 |
| `runs` | `connection` | 最近20次任务，管理员限定 |
| `sync_now`（POST） | `connection`, `full_scan=0/1` | 排队任务号，不等于同步成功 |
| `create_demo`（POST） | `company` | 新模拟连接，管理员限定，不自动同步 |

实体：`supplier`、`item`、`purchase_order`、`payable`、`payment`。查询词最多100字，匹配源单号／内码／供应商／物料编码；每页最多100条。汇总扫描完整匹配范围，按源币种精确计算，只计入state=active的记录；超过一万条不返回部分合计冒充全量。未同步或数据缺失不能解释为零余额。

采购、采购下单、比价、审批和总控Agent增加 `list_external_connections`、`read_external_finance` 只读工具。工具与页面共用查询代码，继续使用现有真实工具审计；不会直接访问金蝶或创建付款、发票、收货单。未授权模型使用的连接不会出现在模型连接目录中。

## 真实接口准备（后续联调时执行）

真实模式需要全部满足，缺一即停止，不回退模拟数据：

1. 由金蝶管理员确认具体版本、WebAPI、第三方应用授权、接口权益、组织／字段／功能／数据权限以及允许的读取范围。
2. 安装并固定与该租户匹配的官方Python SDK。适配器对接官方 `k3cloud_webapi_sdk.main.K3CloudApiSdk` 的 `InitConfig(...)`、`ExecuteBillQuery(data)`。本轮从[金蝶官方SDK页面及其资料包](https://open.kingdee.com/K3Cloud/Open/ApiCenterReportDetail.aspx)核对了这两个签名；没有安装SDK或连接真实租户。旧版资料包不证明客户最新SDK与Python3.14已兼容，需联调验证。
3. 配置连接的HTTPS API地址、应用ID、集成用户、加密应用密钥、账套和组织。站点配置 `erp_finance_live_enabled` 必须明确设为布尔true，`erp_finance_hosts` 必须为允许的主机名JSON数组。默认均未设置，真实网络调用被拒绝。不接受URL凭据、任意端口、私网解析结果或未允许主机。
4. 对每个启用对象填写 `mapping_json`，在租户API中心核对实际FormId和FieldKey、主键粒度、状态及修改标记，然后勾选“已核对真实租户字段与财务口径”。**本版不预填猜测的财务字段。**
5. 用授权的测试账套验收分页、变更／冲销、金额对账和拒绝越权，再显式启用连接与自动同步。SDK安装、许可和网络条件均留待真实联调，不把当前模拟验收当作这些条件已满足。

字段映射结构如下，方括号表示必须替换的租户实际字段，示例本身不能直接启用：

```json
{
  "form_id": "[实际表单标识]",
  "grain": "document",
  "fields": {
    "source_id": "[单据稳定内码]",
    "source_org": "[组织编码字段]",
    "number": "[业务单号字段]",
    "modified_at": "[经验证的修改时间字段]",
    "source_status": "[状态字段]",
    "supplier_code": "[供应商编码字段]",
    "currency": "[币种编码字段]",
    "amount": "[整单金额字段]",
    "outstanding": "[源端权威未结金额字段]"
  },
  "status_map": {"[有效源状态]": "active", "[取消源状态]": "cancelled"}
}
```

标准可选字段还包括 `line_id`, `title`, `item_code`, `uom`, `reference`, `qty`, `rate`, `due_date`。只接受标识符和字段路径，不接受客户端SQL／FilterString。行粒度需稳定的line_id，金额必须是该行的金额；应付与付款首版只允许document粒度，防止按明细重复累计表头金额。

未结金额读取源系统已核对口径的字段，不通过“采购发票总额减全部付款单”推导。`reference`仅保留源关联，不意味着已重建多对多付款分配／核销链；详细核销明细、预付、跨币种及账龄报表需要后续按租户接口补充。

## 同步语义和边界

- 固定UTC读取上界，预留两分钟写入延迟；每实体成功后推进窗口，下次回看十分钟。源无时区时间按配置的固定UTC偏移解释，默认+08:00；不支持需要夏令时历史换算的源时区。
- 每连接使用MariaDB会话锁防并发；配置行锁保护当前实体读取窗口。实体内分页、快照与游标同一事务提交；失败整实体回滚，其他成功实体保留。失败下一次自动同步或手动发起时重试，不无限循环请求厂商。
- 主键含连接、账套、组织、实体、源内码和明细内码；按内容指纹幂等更新，旧修改时间不覆盖新快照。金额以十进制字符串存储并用Decimal计算。
- 一次实体最多200页，每页1–500条，超量失败且不推进游标；当前版不提供长历史自动分片，真实联调数据量超过此范围时需增加时间分片。
- 源取消、作废、反审核、关闭等通过明确状态映射更新；物理删除或撤权不会因“查询不到”自动删除本地记录。全量重扫是重复读取并更新现存对象，**不是物理删除对账**。源端删除事件／全主键对账、正式财务报表对账和人工差异处理尚未实现。
- 固定窗口和重叠不能保证所有源端并发修改都零遗漏；源修改标记、行删除和核销变更传播必须在真实联调验证。无法证明可靠增量时，应暂停自动同步并补专用取数或对账策略。
- 不同步全库，不写回金蝶，不生成本地原生账务单据，不自动覆盖本地Supplier／Item。供应商和物料保留源编码，实际跨系统主数据匹配与采购执行联动留待客户编码确认。
- 不提供财务审计、银行转账或税务开票能力；本地审计记录也不宣称防篡改。

## 验证

不需要凭据的离线验证：

```powershell
$env:PYTHONPATH = (Resolve-Path apps/suke_ops).Path
python -B -m unittest discover -s apps/suke_ops/tests -p test_finance_sync.py -v
node --test tests/test_finance_connections.cjs
```

完整落库验收仅允许在名为 `finance-*` 的独立测试站点执行，会保留合成连接和快照，不在现有业务站点执行：

```text
bench --site finance-v1.local execute suke_ops.finance_sync.integration.run
```

验证五类实体落库、跨页幂等、第二页中断回滚及恢复、部分失败、精确汇总、合成／过期标记、显式账套权限、页面与模型双授权、伪造flags拒绝、Agent注册，以及原生总账／库存账／发票／付款单数量不变。
